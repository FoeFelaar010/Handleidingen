# Handleidingen · Melanchthon Mavo Schiebroek

Stap-voor-stap handleidingen voor leerlingen van Melanchthon Mavo Schiebroek.

- Handleiding aanpassen: pas het Word-bestand aan en upload het in de map `word/`. Verwijder daar de oude versie.
- GitHub zet de site daarna zelf online (tabblad Actions → "Online zetten").
- Nieuwe handleiding: Word-bestand in `word/` en een regel in `src/catalogus.json`.
